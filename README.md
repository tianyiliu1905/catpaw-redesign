# CatPaw 桌面端设计 Demo

这是 CatPaw 桌面端 Agent 的**可交互产品原型**，用于讨论界面、任务路径和工作区交互，而不是已经接入 AI 服务或本机文件系统的桌面应用。主入口是 [`index.html`](./index.html)：它在同一个页面中呈现**首页、任务对话页、摘要和右侧工具工作区**。阅读或修改原型时，请以它为起点，而不是把辅助展示页当作主产品页面。

## 快速预览

直接在浏览器中打开 `index.html` 即可；也可以在仓库目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。项目使用原生 HTML、CSS 和 JavaScript，没有 `package.json`、构建步骤或 npm 依赖。**右侧终端页签里的 `npm run dev` / Vite 输出仅是界面演示内容，不是本仓库的启动命令。** 建议使用现代桌面浏览器；在受限的 `file://` 或隐私环境中，本地存储和剪贴板可能受到浏览器权限限制。

## 产品页面如何组织

`index.html` 的主体可以按「左侧导航 → 中间任务 → 右侧结果与工具」理解：

| 区域 | 原型内容与目的 |
| --- | --- |
| 左侧边栏 | 新建任务、定时任务、专家·技能、资料库、应用、设计系统等入口；独立任务与文件夹内任务分开展示。运行中、新任务、待确认和历史时间使用不同状态提示；支持文件夹收展、排序、任务菜单和子 Agent 状态。办公、开发、设计能力是同层入口，**不再通过场景 Tab 切换**。 |
| 首页 | 随时间变化的问候语、需求输入、智能体/模型展示、归属文件夹与分支选择、访问模式和安全屋开关；下方是「创建数据看板、整理文件、制作幻灯片、写推文」两级 Prompt 推荐及可打开详情的案例。案例可回填 Prompt，也可下载独立 HTML 预览。 |
| 对话页 | 点击侧栏中的「整理本周门店履约异常明细」或「服务零售」文件夹内的「AI 工具约束文件配置与校验」可进入两条预置示例对话。包含多轮消息、轮次刻度导航、产物卡片、子 Agent / AI 任务状态和固定在底部的追问输入框。点产物可在右侧打开预览。 |
| 摘要 | 右上角「摘要」聚合**当前任务产物**和**最近打开**，方便先看结果；右侧工作区关闭时作为内容列，工作区打开时以轻量浮层呈现。它不是文件树的简化版。 |
| 右侧工具工作区 | 右上角「工具」打开后，首先是带目录树的空白「打开文件」页签；通过加号按需新建文件、浏览器和终端页签。同一文件复用页签，目录树可搜索、收起和调整宽度；文件可预览，部分示例可在页面内编辑。文件工作区支持全屏及悬浮的快捷输入框。 |

示例产物包含 PPT、Word、Excel、HTML 和图片；完整目录树还包含 Markdown 与多种代码文件。摘要和对话产物聚焦交付物，完整的文件层级与过程工具则留给右侧工作区。文件夹用同一份 `FOLDERS` 演示数据驱动归属选择、侧栏与工作区目录；演示路径并非真实磁盘目录。

## 建议的体验顺序

1. 在首页点击「创建数据看板」等推荐，观察输入框前的引导标签、二级推荐与案例的变化；打开一张案例，查看预览、Prompt、相似案例及「做同款」。
2. 从侧栏打开「整理本周门店履约异常明细」，查看多轮对话与轮次导航，再点击产物卡片打开右侧预览。
3. 点击「摘要」查看产物与最近打开文件；点击「工具」，在文件树中搜索、打开文件，试用多页签和文件预览。
4. 在案例区打开「我的模版」，体验新建、编辑、复制、分享/导入 JSON 与回填输入框；切换右上角明暗主题并调整窗口宽度或拖动分栏。

首页和对话输入框均可用 **Enter 发送、Shift+Enter 换行**。全局快捷键：**⌘/Ctrl + B** 切换左栏，**⌘/Ctrl + J** 切换右侧工具面板，**⌘/Ctrl + T** 在工作区新建浏览器页签；可用 **Escape** 关闭多数菜单和浮层。分栏拖拽手柄还支持方向键、Home / End。布局会随可用宽度自动让出空间；主动在窄窗口打开右侧工具时，工具可临时替代中间区域。系统设置「减少动态效果」时会减少相关过渡。

## 原型边界

- **没有 AI 推理或真实任务执行**：首页发送只清空输入并输出控制台日志；对话追问会追加用户消息，但不会生成 AI 回复。案例、两条预置对话、产物和状态均为演示数据；不是所有侧栏任务都已实现对话。
- **没有接入本机文件系统**：目录、分支、文件内容和路径来自 `app.js`。示例 Word/Excel 编辑、源码保存、文件重命名/删除等只改变页面内存，刷新后恢复；通过「添加本地文件」选择文件也不读取内容。浏览器页签不实际加载网页，终端不能运行命令，Finder/外部应用入口不执行系统操作。
- **访问模式、安全屋及智能体/Skill/MCP 名称是交互或配置展示**，没有对应权限隔离、能力安装和连接器调用。「我的模版」可用浏览器 `localStorage` 保存配置、导入/导出 JSON，但使用模版只是把文字和引用回填输入框，不会自动绑定能力。
- 明暗主题和自定义模版会尝试存入浏览器本地存储；其他大多数 UI 修改是临时状态。案例 HTML 预览下载、模版 JSON 导入/导出和在获得权限时的复制操作属于浏览器内可用的真实交互。

这个仓库的目标是**验证产品结构和交互体验**。如果需要真正执行 Agent 任务、持久化文件、内嵌浏览器或终端，需要另行接入相应的服务与桌面运行环境；不要从原型中的演示反馈推断这些能力已经实现。
