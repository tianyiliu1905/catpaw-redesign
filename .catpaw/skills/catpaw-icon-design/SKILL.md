# CatPaw 图标设计

## 视觉规则

- 图标原稿用 `viewBox="0 0 24 24"`，无填充，`stroke="currentColor"`，`stroke-width="1.8"`，`stroke-linecap="round"`，`stroke-linejoin="round"`。下载和实际嵌入须保持一致，不依赖预览页 CSS 才能正确呈现。
- 风格圆润、可爱但克制：一个主轮廓 + 最少的识别细节；优先圆角矩形与弧线，避免细密线段、重复描边、过小或拥挤的装饰。放在 14–16px 下仍要可辨认。
- 长方形主体以「专家·技能·连接器」为宽度基准：通常 `x=3…21`，宽 18 个坐标单位；圆形、箭头、书页等按光学尺寸调整，不机械套矩形。外框圆角参考 `rx=5…5.5`，文件夹角约 3.5–4；始终为内部笔画留呼吸空间。
- 同义图形复用同一轮廓；「新建」态在主体中间加入小型 `+`（当前两笔各 6 单位，中心依内部可用空间调整），不要顶到边框，也不要与横线相交。新任务实际是**新建对话**，主体为气泡；新建文件夹用同尺寸居中加号。
- 图标的语义优先于抽象装饰：文件夹系列共享轮廓；打开态表现展开的前盖；资料库为摊开书册；设计资源为简洁素材画板；网站·NoCode 可以保留猫咪识别性。参考图若以连续曲线表达形体，不要拆成许多短线；内部识别细节能合并就合并。

## 设计与验收流程

1. 先盘点目标界面的图标语义与复用关系，排除品牌 Logo、二维码、彩色文件类型资产和插画；相同语义只设计一次，别按 DOM 次数重复绘制。
2. 在 `icon-preview.html` 的图标卡片内设计真正的 SVG；卡片名和下载名反映语义，深色侧栏预览也要同步。预览用 Keyline 由模板独立叠加，不得混入图标本体或下载文件。
3. 必须逐段检查 SVG 的**实际描边**，不只看路径中心线：在无 Keyline 的浅色和深色背景分别放大查看拐弯、交叉、端点与回环。非刻意交叉的两段中心线若距离不足描边宽度（默认 1.8 单位），圆头/圆角就会叠成粗块；应调整路径、合并共线段或留足可见缝隙。避免用两条路径重复描绘同一边、端点贴住别的线、线条穿过回环；真正需要相接的线以单一路径连续绘制。任何不规则加粗、意外叠线、毛刺或缩小后糊成一团，均视为**验收失败**，必须修正后才能交付。
4. 比较 16、24、32px 与深色背景效果；检查圆角、对齐、轮廓视觉宽度、笔画密度、留白及断口。缩小时相邻笔画不能粘连；检查下载 SVG 的完整属性。
5. 若要将图标应用到 `index.html` 或 `app.js`，先获得明确要求或确认范围；不要未经要求覆盖主 UI。复用同一 SVG 路径，避免预览与实际页面漂移。
6. 改动后检查 HTML/SVG 诊断，保留用户已有的其他改动。

## 既有原型

`icon-preview.html` 中的 9 款基础图标是本系列的视觉基准；主页面未定制的线性图标也已按语义收录在该页的分组卡片里。不要将预览的 Keyline、粉色辅助线、浅色背景当成 SVG 的一部分。
